# PolarSense Media & Visual Assets

This directory contains visual documentation and imagery for the PolarSense autonomous profiling float.

## Directory Contents

- `architecture.svg`: High-resolution vector architecture diagram of the PolarSense float, Iridium communications link, and ground ingest pipeline.
- `media/screenshots/`: Captured screens of the PolarSense Web Operations Ground Station running on **SYNTHETIC data**.

> **IMPORTANT**:
> 1. All dashboard screenshots depict simulated and synthetic data.
> 2. Laboratory prototype photographs will be added in accordance with SIH submission guidelines.
> 3. No field deployment photos are claimed, as the project is strictly at **TRL 4**.
